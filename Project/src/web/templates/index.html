System Architecture & Methodology

1

MIME Parsing & Ingestion

Deconstructs RFC822 / MIME emails into structured headers, body payload, links, and attachments.

2

Sender & Header Authenticity

Analyzes SPF, DKIM, DMARC alignment, brand display name spoofing, and Levenshtein typosquatting.

3

Link & URL Safety Analysis

Detects masked hyperlinks (anchor vs target href), checks PhishTank/OpenPhish feeds, IP hosts, and shorteners.

4

Linguistic & NLP Analysis

Evaluates urgency cues, coercion threats, credential harvesting patterns, and generic salutations.

5

Machine Learning Engine

Trained Random Forest classifier combining engineered security features with TF-IDF n-gram text vectors.

6

Rule-Based Aggregation

Blends ML probability with deterministic escalation overrides into final Safe, Suspicious, or Phishing labels.
